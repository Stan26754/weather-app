# BMF Weather App

A simple weather web application built with HTML, CSS, JavaScript, Python, Flask, and the OpenWeather API.

## Features

- Search for any city
- Get current temperature
- View feels-like temperature
- View humidity
- View current weather conditions
- Handles invalid city searches

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- OpenWeather API

## How it works

The frontend sends the user's city to the Flask backend.

Flask then requests weather data from OpenWeather and sends the result back to the frontend.

The OpenWeather API key is stored in an environment file and is not included in the repository.
